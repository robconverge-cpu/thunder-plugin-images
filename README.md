# Thunder Plugins images

Public image hosting for Thunder Plugins Discord posts. Link files with
`https://raw.githubusercontent.com/robconverge-cpu/thunder-plugin-images/main/<path>`.

- `headers/`: channel and release headers, 1200x400 (PNG and animated GIF)
- `icons/`: plugin icons, 512px
- `emoji/`: Discord emoji, 128px
- `logo/`: Thunder Plugins logos (horizontal, stacked, wordmark, volt mark), for dark backgrounds
- `posts/`: ready-made post images (`plugin-list.png`)

Source of truth is the brand kit in `.CLAUDE/projects/thunder-brand`; re-copy from there after a rebuild.
